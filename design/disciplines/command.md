# Command

*You give one clear instruction when every channel is talking at once.*

**Status:** Playtest proposal - expanded field, untested.

## Rules

Tactical coordination, delegation, morale and organised teams. Influence negotiates consent; Command coordinates willing allies.

Ranks 1, 2 and 3 are purchased in order. Ranks unlock abilities; they add no passive bonus. Home 1/2/4 DP; Adjacent 2/4/8; Foreign 3/6/12; Opposed 4/8/16. No discipline purchases at level 0.

## Coverage direction

Novice: reliable basic task and one support option. Adept: a pressured multi-step task and a meaningful reaction or alternative approach. Master: a defining high-stakes application with explicit limits.
