# Helmet Comms

**Status:** Playtest proposal - untested.

## Rules

**Category:** Communications · **Damage type:** None · **Bulk:** 0 · **Hands:** 0 · **Cost:** 25 coins

Hands-free voice communication between paired units up to 100 metres away with a clear signal path. Dense structures or jamming can block the link. It pairs with a compatible comms array for longer links.
