# Rescue Winch

**Status:** Playtest proposal - untested.

## Rules

**Category:** Mobility · **Damage type:** None · **Bulk:** 2 · **Hands:** 2 · **Cost:** 110 coins

Anchor the winch to a sound fixture. One operator can reel in a 20-metre line attached to one explorer or an equivalent load. The winch requires a clear path and cannot lift through an obstruction.
