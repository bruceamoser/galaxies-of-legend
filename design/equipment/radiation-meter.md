# Radiation Meter

**Status:** Playtest proposal - untested.

## Rules

**Category:** Sensor · **Damage type:** None · **Bulk:** 0 · **Hands:** 1 · **Cost:** 45 coins

A Main Action reads local ionizing radiation at the meter and indicates whether it is rising, falling or stable. It does not locate a shielded source or reduce exposure.
