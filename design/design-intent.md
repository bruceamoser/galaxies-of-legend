# The experience we are building

**Agreed direction:** a lived-in science-fiction frontier, a small crew, and a ship that feels like a member of that crew. The game should be playable first on a planet or station, then aboard a ship. Space fantasy, not hard-SF simulation.

## Start with the moment

A Soldier steps into the corridor and makes the line hold. A Scientist looks at a dead alien mechanism and says the thing everyone else missed. A Spacer keeps the ship alive with a borrowed fuse and a bad idea. An Explorer finds the route nobody else could see. A Medic decides who gets another hour. An Envoy makes a room decide what it already wanted.

These are design promises, not restrictions on a character's personality. Class signatures express the promise; shared abilities let any class branch out.

## Review each option as a player

- Can I picture what my character does?
- Would I choose this because I want that moment, not because I need a tax paid?
- Does it give me a new decision or a satisfying expression of expertise?
- Does Weak still advance the scene, with Standard and Strong delivering more?
- Can another player help set this up or enjoy what it creates?
- Can we resolve it without stopping to negotiate a new subsystem?

## GOL identity

- **Planet-first, ship-second.** A settlement, station or wilderness is a complete adventure. The ship extends the game; it does not replace it.
- **Stations are jobs; classes are people.** Never make a class that is only a bridge seat.
- **The ship is a shared character.** Hull, DR, systems and Consumable Dice are one coherent sheet.
- **Preparation is the FTL adventure.** Fuel, money, route plotting and ship condition create the tension; transit is instant.
- **One engine everywhere.** Personal combat, social play, exploration, ship combat and FTL use the same 3d6 and the same three bands.
- **Bounded choices.** Every option spends from a defined budget. No category smuggles in another category's power.

## Read it aloud

Read every new entry aloud before keeping it. If it sounds like a proof, replace the explanation with the thing the character does and the consequence at the table. Give distances and limits a scene to belong to.
