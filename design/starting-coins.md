# Starting coins

**Playtest target:** 50–70 coins after card-granted equipment.

**Starting coins = 40 + homeworld + culture + background + class.**

Add these once after completing level 1. This is a starting purse, not income each level. It does not use DP or attributes. Resolve card equipment grants before shopping; there is no coin reimbursement for a duplicate or declined grant.

## Checks

Minimum: Beltborn + Frontier Settlement + Ship Mechanic + Soldier = 40 + 0 + 5 + 7 + 4 = **56**.
Maximum: Core World + Corporate Arcology + Field Medic + Scientist = 40 + 1 + 10 + 10 + 8 = **69**.

Every combination in this seed falls between 56 and 69 coins before shopping. The market lists prices; purchases still consume Bulk and obey hand requirements.
