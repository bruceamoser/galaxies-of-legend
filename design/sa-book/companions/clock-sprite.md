# Clock Sprite

**Status:** Playtest proposal - untested personal companion.

**Family:** Sprite · **Minimum controller level:** 1 · **License price:** 50 coins

**Access:** Working data slate or terminal with existing authorized access.

No physical body, HP, movement, defenses or carrying capacity.

**Attributes:** Brawn 0; Fortitude 0; Agility 0; Guile 0; Knowledge 0; Reason +1.

**Senses and reporting:** Reads only data the host exposes under existing permissions.

## Align the Logs

**Action:** Maneuver · **Attribute:** None (no roll)

**Target / range / shape:** Two accessible timestamps and their documented time offsets.

Display both times on the same reference clock. If an offset is unknown, label that time uncertain.

**Limits:** Use one paid command package under Drones, Sprites and Companions in Player’s Book Chapter 9. No independent activity or Reaction.
