# Raster ship-sheet art

Generated with the built-in image-generation tool. These painted hulls replace the visual direction of the rejected vector-sheet prototype. They are artwork proofs, awaiting typeset system fields and sheet integration. Blank panels represent module positions; required equipment must still be purchased with SP. Ship geometry adds no new rules.

`light-cutter-spatial-v2.png`: Light Cutter, twelve blank system panels.

`medium-frigate-spatial-v2.png`: Medium Frigate, sixteen blank system panels.

Generation prompts are recorded in `prompts.json`.
