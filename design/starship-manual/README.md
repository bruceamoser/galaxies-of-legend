# Galaxies of Legend Starship Manual

Owns construction, system capability and wear, station actions, ship combat, transfers, repair, FTL, budgeted examples and ship records. All numerical ship procedures remain untested playtest proposals.

- `manuscript/01-welcome.md`: introduction and three-book reading guide.
- `manuscript/02-rules.md`: single canonical ship rules source, moved intact from the Player's Book.
- `manuscript/03-reference.md`: quick reference and record guidance.
- `ship-sheets.typ`: the two printable ship records, removed from the Player's Book.
- `book.typ`, `cover.typ`: assembly entry points regenerated by the companion publisher.
- `../ships/construction.json`, `../ships/examples.json`, `../ship_builder.py`: allocation data, checked examples and validator.

Build the Player's Book first for shared assets, then `python3 design/publishing/build_companions.py starship-manual`. The PDF is `output/galaxies-of-legend-starship-manual.pdf`. `generated/` and `output/` are disposable. Shared typography and Markdown rendering live in the Player's Book pipeline; edit Markdown, sheets or the publisher instead of generated body files.

The Player's Book owns learned abilities and the full 280-entry personal wound foundation. This manual references class signatures in Player's Book Chapter 4 and shared abilities in Chapter 8. Sector preparation and opposition live in the SA book.
