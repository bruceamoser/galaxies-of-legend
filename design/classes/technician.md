# Technician

*You make machines useful where the manual has run out.*

**Status:** Playtest proposal - new class and signatures, untested.

## Rules

**Class foundations:** minimum 0 in Knowledge, Reason; HP contribution +2. No multiclassing.

**Starting disciplines:** choose two distinct rank-1 disciplines from Robotics, Engineering, Computing, Science, Armor.

**Discipline pricing:** Home: Robotics, Engineering. Adjacent: Computing, Science, Trade, Armor. All others Foreign; no Opposed disciplines.

**Class role:** Robotics, fixtures and industrial systems, distinct from the Spacer's ship manoeuvring and power sacrifice.

Choose one class-exclusive signature at levels 1, 3 and 7. Extra signatures cost 2/4/8 DP. No discipline requirements.
