# Scientist

*You solve the problem everyone else has accepted as weather.*

**Status:** Playtest proposal - expanded affinity profile, untested.

## Rules

**Class foundations:** minimum 0 in Knowledge, Reason; HP contribution +2. No multiclassing.

**Starting disciplines:** choose two distinct rank-1 disciplines from Science, Computing, Xenology, Investigation, Robotics.

**Discipline pricing:** Home: Science, Computing. Adjacent: Xenology, Investigation, Robotics, Engineering, Medicine. All others Foreign; no Opposed disciplines.

Choose one class-exclusive signature at levels 1, 3 and 7. Extra signatures cost 2/4/8 DP. No discipline requirements.
