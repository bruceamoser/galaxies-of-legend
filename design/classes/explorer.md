# Explorer

*You go first, because the map is not going to draw itself.*

**Status:** Playtest proposal - expanded affinity profile, untested.

## Rules

**Class foundations:** minimum 0 in Agility, Reason; HP contribution +3. No multiclassing.

**Starting disciplines:** choose two distinct rank-1 disciplines from Navigation, Survival, Piloting, Athletics, Xenology.

**Discipline pricing:** Home: Navigation, Survival. Adjacent: Piloting, Athletics, Science, Xenology, Investigation. All others Foreign; no Opposed disciplines.

Choose one class-exclusive signature at levels 1, 3 and 7. Extra signatures cost 2/4/8 DP. No discipline requirements.
