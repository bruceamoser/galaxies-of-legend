# Isolate the Fault

**Status:** Playtest proposal - untested.

## Rules

**Action:** Reaction · **Attribute:** Knowledge

**Target / range / shape:** One device within reach when a fault would interrupt its operation

Disconnect a failing accessory from the device before it takes the rest offline. The accessory must be physically separable.

- **Weak:** Shut down both safely.
- **Standard:** Keep the device running through its current action. The accessory shuts down.
- **Strong:** Keep the device running for the scene. The accessory shuts down.

**Duration:** By outcome

**Equipment / acquisition:** Toolkit

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Class Technician; minimum level 3

**Type:** Signature

**Tags:** Technician

**Limits:** Pay the action and stated time. This card grants no improvement to installed system dice.
