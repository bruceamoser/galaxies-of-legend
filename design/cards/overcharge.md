# Overcharge

*You ask the plant for more than the manual allows and promise to explain later.*

## Rules

**Action:** Main Action · **Attribute:** Knowledge

**Target / range / shape:** One ship system within reach

Push a system beyond its rating.

- **Weak:** increase the system die one step for the scene; it steps down one size at the end of the scene.
- **Standard:** increase the system die one step for the scene.
- **Strong:** increase two different systems one step for the scene.

**Duration:** One scene.

**Equipment / acquisition:** Requires a toolkit and access to the power plant

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Engineering 2

**Type:** Skill / Technical

**Tags:** Technical / Ship

**Limits:** Repeatable; pay the action and any stated costs each use.

**ID:** overcharge
