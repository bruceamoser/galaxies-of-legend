# Release the Load

**Status:** Playtest proposal - untested.

## Rules

**Action:** Reaction · **Attribute:** None (no roll)

**Target / range / shape:** One crew-controlled robot within command range when its load snags

Command it to release the load if the gripper still works. The load falls or stays caught as appropriate.

**Duration:** Instant unless the effect states a duration.

**Equipment / acquisition:** Requires any equipment named above. Grants no equipment.

---

**Tier / minimum level:** 7 · **DP:** 8 · **Requirements to learn:** Robotics 3

**Type:** Skill / Utility

**Tags:** Robotics / Reaction

**Limits:** Pay the listed action each use. Any granted Boon applies once and does not stack with itself.
