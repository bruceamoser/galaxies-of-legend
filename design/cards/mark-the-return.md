# Mark the Return

**Status:** Playtest proposal - untested.

## Rules

**Action:** Maneuver · **Attribute:** None (no roll)

**Target / range / shape:** Self on a route you have used

Leave a return marker or record a fix. Gain 1 Boon on your next Reason check this scene to retrace or navigate that route.

**Duration:** As stated above.

**Equipment / acquisition:** Requires any equipment named above. Grants no equipment.

---

**Tier / minimum level:** 1 · **DP:** 2 · **Requirements to learn:** Navigation 1

**Type:** Skill / Utility

**Tags:** Navigation / Maneuver

**Limits:** Any granted Boon applies once and does not stack with itself.
