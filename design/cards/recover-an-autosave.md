# Recover a Record

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Knowledge

**Target / range / shape:** One accessible local data store with damaged or incomplete records

Recover a specified readable record. On completing 3 progress, recover the available contents and identify any sections that no longer survive. No access rights are gained.

- **Weak:** 1 progress.
- **Standard:** 2 progress.
- **Strong:** 3 progress.

**Duration:** Progress remains on the declared task until it resolves or circumstances invalidate it.

**Equipment / acquisition:** Requires appropriate access and any equipment named in the effect.

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Computing 2

**Type:** Skill / Utility

**Tags:** Computing / Main Action

**Limits:** Spend the listed action. Resolve the printed result once.
