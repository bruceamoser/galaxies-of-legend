# Cross-Check the Fix

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Reason

**Target / range / shape:** One current position you can compare to a chart, landmark, or recorded fix

Resolve an uncertain position. On completing 3 progress, obtain a usable fix or determine which measurement is still unavailable. This is a personal or local navigation task and does not replace a ship plotting check.

- **Weak:** 1 progress.
- **Standard:** 2 progress.
- **Strong:** 3 progress.

**Duration:** Progress remains on the declared task until it resolves or circumstances invalidate it.

**Equipment / acquisition:** Requires appropriate access and any equipment named in the effect.

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Navigation 2

**Type:** Skill / Utility

**Tags:** Navigation / Main Action

**Limits:** Spend the listed action. Resolve the printed result once.
