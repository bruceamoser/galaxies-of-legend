# Catch the Confound

**Status:** Playtest proposal - untested.

## Rules

**Action:** Reaction · **Attribute:** None (no roll)

**Target / range / shape:** One experiment you observe when a second variable visibly changes

Flag the measurement as confounded and record the changed variable before the record is finalized.

**Duration:** Instant unless the effect states a duration.

**Equipment / acquisition:** Requires any equipment named above. Grants no equipment.
