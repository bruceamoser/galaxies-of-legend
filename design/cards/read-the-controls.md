# Read the Controls

**Status:** Playtest proposal - untested.

## Rules

**Action:** Maneuver · **Attribute:** None (no roll)

**Target / range / shape:** One vehicle console you can operate

Locate the controls you need and gain 1 Boon on your next Agility check this turn to pilot that vehicle. Ship system rolls are unchanged.

**Duration:** As stated above.

**Equipment / acquisition:** Requires any equipment named above. Grants no equipment.

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Piloting 2

**Type:** Skill / Utility

**Tags:** Piloting / Maneuver

**Limits:** Any granted Boon applies once and does not stack with itself.
