# Redirect a Routine

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Knowledge

**Target / range / shape:** One accessible crew-controlled device or robot and one permitted instruction

Diagnose and revise the next step of a permitted routine. At 3 progress install the change. A controlled robot still requires a paid command to act.

- **Weak:** 1 progress.
- **Standard:** 2 progress.
- **Strong:** 3 progress.

**Duration:** Progress remains on the declared task until it resolves or circumstances invalidate it.

**Equipment / acquisition:** Requires appropriate access and any equipment named in the effect.

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Robotics 2

**Type:** Skill / Utility

**Tags:** Robotics / Main Action

**Limits:** Spend the listed action. Resolve the printed result once.

**ID:** audit-the-routine
