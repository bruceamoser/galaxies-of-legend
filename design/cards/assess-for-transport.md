# Assess for Transport

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Knowledge

**Target / range / shape:** One reachable patient and a declared evacuation task

Contribute to a progress task to prepare or move a patient with the means on hand. Completing the track gets them to the agreed safe position if the path is clear. This restores no HP and removes no wounds.

- **Weak:** 1 progress.
- **Standard:** 2 progress.
- **Strong:** 3 progress.

**Duration:** Progress remains on the declared task until it resolves or circumstances invalidate it.

**Equipment / acquisition:** Requires appropriate access and any equipment named in the effect.

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Medicine 2

**Type:** Skill / Utility

**Tags:** Medicine / Main Action

**Limits:** Spend the listed action. Resolve the printed result once.
