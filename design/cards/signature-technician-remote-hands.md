# Remote Hands

*You make machines useful where the manual has run out.*

**Status:** Playtest proposal - new signature, untested.

## Rules

**Action:** Main Action · **Attribute:** Knowledge

**Target / range / shape:** One owned utility robot within 8 squares and one reachable non-combat task

Direct the robot to carry a small object, press a control or inspect a panel. It takes no independent turn and cannot use your abilities or attack.

- **Weak:** complete a routine task, but the robot remains exposed at the work site.
- **Standard:** complete a routine task and return the robot to you.
- **Strong:** complete the task, return it and identify one visible hazard at the work site.

**Duration:** Instant; movement follows a physically open route of at most 8 squares each way.

**Equipment / acquisition:** Requires an existing functioning utility robot; this ability grants none

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Class Technician; minimum level 3

**Type:** Signature

**Tags:** Technician

**Limits:** Do not stack multiple instances of the same benefit; each granted Boon applies once. Pay the action and any stated time.
