# Paper Trail

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Guile

**Target / range / shape:** One inspection desk you can contact; one hour

Submit a coherent set of supporting documents for a fictional identity. Independent verification can expose it.

- **Weak:** Learn which document is missing.
- **Standard:** Pass one routine desk review.
- **Strong:** Pass the review and learn which office handles follow-up.

**Duration:** Instant unless an outcome states a duration.
