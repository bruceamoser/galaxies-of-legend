# Plot Course

*You turn a list of coordinates into a route a frightened crew can follow.*

## Rules

**Action:** Main Action · **Attribute:** Reason

**Target / range / shape:** One route or destination

Make progress on a navigation task.

- **Weak:** 1 progress; note one complication.
- **Standard:** 2 progress.
- **Strong:** 3 progress; the next jump or journey on this route gains a Boon.

**Duration:** The progress and Boon persist until the journey is complete.

**Equipment / acquisition:** Requires charts or a nav computer

---

**Tier / minimum level:** 1 · **DP:** 2 · **Requirements to learn:** Navigation 1

**Type:** Skill / Navigation

**Tags:** Navigation / Support

**Limits:** Repeatable; pay the action and any stated costs each use.

**ID:** plot-course
