# Diagnostic Pass

*You make machines useful where the manual has run out.*

**Status:** Playtest proposal - new signature, untested.

## Rules

**Action:** Main Action · **Attribute:** Knowledge

**Target / range / shape:** One accessible device, system interface, or non-hostile robot within reach

Diagnose one stated fault. At 3 progress locate the cause and name a safe access point or confirm what further evidence is missing. Diagnosis restores no HP or system die.

- **Weak:** 1 progress.
- **Standard:** 2 progress.
- **Strong:** 3 progress.

**Duration:** Progress lasts until the task resolves or the situation invalidates it.

**Equipment / acquisition:** Requires a toolkit and access to the device

---

**Tier / minimum level:** 1 · **DP:** 2 · **Requirements to learn:** Class Technician; minimum level 1

**Type:** Signature

**Tags:** Technician

**Limits:** Do not stack multiple instances of the same benefit; each granted Boon applies once. Pay the action and any stated time.
