# Coordinate the Operation

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Reason

**Target / range / shape:** Up to four willing allies who can receive your instructions

Coordinate a shared noncombat task with a declared progress track. Add progress only if at least one ally can carry out a concrete part of the plan. Your contribution supplies instructions, never an extra action or progress on a task the crew cannot attempt.

- **Weak:** 1 progress.
- **Standard:** 2 progress.
- **Strong:** 3 progress.

**Duration:** Progress remains on the declared task until it resolves or circumstances invalidate it.

**Equipment / acquisition:** Requires appropriate access and any equipment named in the effect.

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Command 2

**Type:** Skill / Utility

**Tags:** Command / Main Action

**Limits:** Spend the listed action. Resolve the printed result once.

**ID:** set-the-rendezvous
