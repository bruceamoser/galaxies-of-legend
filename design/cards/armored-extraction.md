# Armored Extraction

**Status:** Playtest proposal - untested.

## Rules

**Action:** Maneuver · **Attribute:** None (no roll)

**Target / range / shape:** One willing or incapacitated adjacent ally; both fit the route

Move one square with the ally into adjacent cover. This requires a free hand and enough Capacity for the load.

**Duration:** Instant unless the effect states a duration.

**Equipment / acquisition:** Requires any equipment named above. Grants no equipment.

---

**Tier / minimum level:** 7 · **DP:** 8 · **Requirements to learn:** Armor 3

**Type:** Skill / Utility

**Tags:** Armor / Maneuver

**Limits:** Pay the listed action each use. Any granted Boon applies once and does not stack with itself.
