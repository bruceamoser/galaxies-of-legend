# Rebuild the Interface

*You make machines useful where the manual has run out.*

**Status:** Playtest proposal - new signature, untested.

## Rules

**Action:** Main Action · **Attribute:** Knowledge

**Target / range / shape:** One compatible owned device or system; one uninterrupted hour

Adapt an existing interface to restore access, not improve its installed rating. Requires the failed controls to be accessible.

- **Weak:** restore one lost control function for the next action.
- **Standard:** restore that control function for the scene.
- **Strong:** restore it until proper service and give its next operator check a Boon.

**Duration:** By result; existing power, damage and safety limits still apply.

**Equipment / acquisition:** Requires a toolkit, suitable replacement components and an otherwise functioning system

---

**Tier / minimum level:** 7 · **DP:** 8 · **Requirements to learn:** Class Technician; minimum level 7

**Type:** Signature

**Tags:** Technician

**Limits:** Do not stack multiple instances of the same benefit; each granted Boon applies once. Pay the action and any stated time.
