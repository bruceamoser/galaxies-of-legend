# Rally to Cover

**Status:** Playtest proposal - untested.

## Rules

**Action:** Maneuver · **Attribute:** Fortitude

**Target / range / shape:** Up to two allies within speaking distance who can see the same cover

Call a fallback position.

- **Weak:** One ally can move one square toward it.
- **Standard:** Both allies can each move one square toward it.
- **Strong:** Both allies can each move up to two squares toward it.

**Duration:** Instant unless an outcome states a duration.

**Equipment / acquisition:** Requires the access, tools or equipment stated above.

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Class Soldier; minimum level 3

**Type:** Signature

**Tags:** Soldier

**Limits:** Each granted Boon or Bane applies once. Repeated uses do not stack.
