# Spoof a Handshake

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Agility

**Target / range / shape:** One network port you can access and one valid credential you control; ten minutes

Use a valid credential to mimic a routine peripheral. This grants no additional access rights.

- **Weak:** Identify the expected peripheral type.
- **Standard:** Connect for one permitted read operation.
- **Strong:** Connect for one permitted read and one permitted write operation.

**Duration:** Instant unless an outcome states a duration.

**Equipment / acquisition:** Requires the access, tools or equipment stated above.
