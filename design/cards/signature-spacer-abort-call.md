# Abort Call

**Status:** Playtest proposal - untested.

## Rules

**Action:** Reaction · **Attribute:** None (no roll)

**Target / range / shape:** One willing pilot within comms before they roll to avoid a hazard you can perceive

Give the pilot 1 Boon on their Agility roll to avoid the hazard. Use the printed station attribute instead if an applicable ship action names a different attribute.

**Duration:** As stated in the effect.

**Equipment / acquisition:** Requires the access, tools or equipment stated above.

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Class Spacer; minimum level 3

**Type:** Signature

**Tags:** Spacer

**Limits:** Each granted Boon or Bane applies once. Repeated uses do not stack.
