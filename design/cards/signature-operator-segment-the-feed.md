# Segment the Feed

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Agility

**Target / range / shape:** One surveillance network segment you can administer; one hour

Reroute one camera feed to an authorized local recorder for maintenance.

- **Weak:** Identify the affected endpoints.
- **Standard:** Reroute the feed for the scene with a visible maintenance alert.
- **Strong:** Reroute it for the scene and preserve both original and replacement timestamps.

**Duration:** Instant unless an outcome states a duration.

**Equipment / acquisition:** Requires the access, tools or equipment stated above.
