# Emergency Jump

*You plot a jump with incomplete charts and a crew who would rather leave than explain.*

## Rules

**Action:** Main Action · **Attribute:** Reason

**Target / range / shape:** One ship and a calculated escape route

Make a hurried FTL plot. The SA sets the progress needed (usually 3).

- **Weak:** 1 progress; the route is valid but arrives off target.
- **Standard:** 2 progress; the route is valid and arrives as intended.
- **Strong:** 3 progress; the jump can be made immediately, even under fire.

**Duration:** The route remains valid for one jump.

**Equipment / acquisition:** Requires charts or a nav computer

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Navigation 2

**Type:** Skill / Navigation

**Tags:** Navigation / Ship

**Limits:** Repeatable; pay the action and any stated costs each use.
