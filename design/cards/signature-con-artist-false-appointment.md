# False Appointment

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Guile

**Target / range / shape:** One receptionist you can speak with; ten minutes

Use a plausible calendar entry to obtain a meeting.

- **Weak:** Learn who verifies the booking.
- **Standard:** Secure a supervised meeting with an assistant.
- **Strong:** Secure a supervised meeting with the named contact if present.

**Duration:** Instant unless an outcome states a duration.

**Equipment / acquisition:** Requires the access, tools or equipment stated above.

**Type:** Signature

**Tags:** Con Artist

**Limits:** Each granted Boon or Bane applies once. Repeated uses do not stack.
