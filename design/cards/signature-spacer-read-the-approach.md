# Read the Approach

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Reason

**Target / range / shape:** One visible docking approach or recorded traffic feed

Identify how local traffic reaches a berth.

- **Weak:** Identify the main traffic direction.
- **Standard:** Identify one viable approach and its next hazard.
- **Strong:** Also identify a viable abort route if one exists.

**Duration:** Instant unless an outcome states a duration.

**Equipment / acquisition:** Requires the access, tools or equipment stated above.
