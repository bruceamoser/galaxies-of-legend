# Hypothesis

*You state what must be true and then find the detail that proves it.*

## Rules

**Action:** Main Action · **Attribute:** Reason

**Target / range / shape:** One visible creature, object or phenomenon

Analyse the target. The SA sets the progress needed (usually 3).

- **Weak:** 1 progress; identify one obvious property.
- **Standard:** 2 progress; identify a weakness or hidden property.
- **Strong:** 3 progress; the next ally to attack or act on your analysis gains a Boon.

**Duration:** The analysis persists for the scene.

**Equipment / acquisition:** Requires a sensor pack or laboratory access

---

**Tier / minimum level:** 1 · **DP:** 2 · **Requirements to learn:** Class Scientist; minimum level 1

**Type:** Signature

**Tags:** Technical / Support

**Limits:** Repeatable; pay the action and any stated costs each use.

**ID:** signature-scientist-hypothesis
