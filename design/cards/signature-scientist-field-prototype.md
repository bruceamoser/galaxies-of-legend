# Field Prototype

*You build the thing the mission needed five minutes ago.*

## Rules

**Action:** Main Action · **Attribute:** Knowledge

**Target / range / shape:** One device or problem within reach; 10 minutes

Build a temporary device with one clear function agreed with the SA.

- **Weak:** it works once, then breaks.
- **Standard:** it works for the scene.
- **Strong:** it works for the scene and can be used three times before breaking.

**Duration:** One use, one scene, or three uses, by result.

**Equipment / acquisition:** Requires a toolkit

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Class Scientist; minimum level 3

**Type:** Signature

**Tags:** Technical / Utility

**Limits:** Repeatable; pay the action and any stated costs each use.

**ID:** signature-scientist-field-prototype
