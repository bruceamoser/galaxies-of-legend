# Countertrace

**Status:** Playtest proposal - untested.

## Rules

**Action:** Reaction · **Attribute:** Agility

**Target / range / shape:** One accessible terminal when a trace begins on a session you control

End the session and examine the trace request. Existing logs remain.

- **Weak:** Disconnect the session.
- **Standard:** Disconnect and identify the immediate relay if visible.
- **Strong:** Also record the request timestamp and its stated origin.

**Duration:** Instant unless an outcome states a duration.

**Equipment / acquisition:** Requires the access, tools or equipment stated above.

---

**Tier / minimum level:** 7 · **DP:** 8 · **Requirements to learn:** Class Operator; minimum level 7

**Type:** Signature

**Tags:** Operator

**Limits:** Each granted Boon or Bane applies once. Repeated uses do not stack.

**ID:** signature-operator-countertrace
