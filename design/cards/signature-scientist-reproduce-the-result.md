# Reproduce the Result

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Knowledge

**Target / range / shape:** One documented experiment with available materials; one hour

Run the experiment again under its recorded conditions.

- **Weak:** Identify one step you cannot reproduce reliably.
- **Standard:** Obtain a repeat result and record discrepancies.
- **Strong:** Also test one deliberate variation and record its effect.

**Duration:** Instant unless an outcome states a duration.

**Equipment / acquisition:** Requires the access, tools or equipment stated above.

**Type:** Signature

**Tags:** Scientist

**Limits:** Each granted Boon or Bane applies once. Repeated uses do not stack.
