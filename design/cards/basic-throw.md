# Basic Throw

**Status:** Playtest proposal.

## Rules

**Action:** Main Action · **Attribute:** Brawn

**Target / range / shape:** One visible creature within 3 squares

Throw a suitable object. It lands in the target square.

- **Weak:** 2 Physical damage.
- **Standard:** 3 Physical damage.
- **Strong:** 5 Physical damage.

**Duration:** As stated in the effect.

**Equipment / acquisition:** Requires a suitable object you can throw.
