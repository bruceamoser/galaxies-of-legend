# Read the Weather Break

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Reason

**Target / range / shape:** One exposed route, camp, or work site whose conditions you can observe

Assess a safe window or shelter. At 3 progress identify a workable route, window or site from the evidence, or establish which hazard still blocks it.

- **Weak:** 1 progress.
- **Standard:** 2 progress.
- **Strong:** 3 progress.

**Duration:** Progress remains on the declared task until it resolves or circumstances invalidate it.

**Equipment / acquisition:** Requires appropriate access and any equipment named in the effect.
