# Map the Interaction

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Knowledge

**Target / range / shape:** Two measured phenomena in one accessible site; one hour

Compare their behavior to find when one affects the other.

- **Weak:** Identify a measurable correlation.
- **Standard:** Identify a repeatable condition under which the interaction occurs if present.
- **Strong:** Also identify a safe intervention that can interrupt it if feasible.

**Duration:** Instant unless an outcome states a duration.

**Equipment / acquisition:** Requires the access, tools or equipment stated above.

**Type:** Signature

**Tags:** Scientist

**Limits:** Each granted Boon or Bane applies once. Repeated uses do not stack.
