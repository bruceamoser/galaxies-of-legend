# Make Camp

*You make a place to stop before the weather decides for you.*

**Status:** Playtest proposal - starter coverage, untested.

## Rules

**Action:** Main Action · **Attribute:** Reason

**Target / range / shape:** One campsite; ten minutes

Prepare shelter against one declared ordinary weather hazard. The SA sets progress, usually 3. Completion provides shelter, not immunity to extreme exposure.

- **Weak:** 1 progress; the camp is conspicuous.
- **Standard:** 2 progress.
- **Strong:** 3 progress; identify one safe exit from the campsite.

**Duration:** Until the party leaves or the weather changes substantially.

**Equipment / acquisition:** Requires suitable shelter materials

---

**Tier / minimum level:** 1 · **DP:** 2 · **Requirements to learn:** Survival 1

**Type:** Skill / Utility

**Tags:** Survival

**Limits:** One instance of this card's benefit per target or task; repeat only for new progress, a new trigger or a changed situation. Pay the printed action and time.
