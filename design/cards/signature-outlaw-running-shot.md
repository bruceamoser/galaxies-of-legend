# Running Shot

*You find work beyond the safe lanes and leave before the warrants arrive.*

**Status:** Playtest proposal - new signature, untested.

## Rules

**Action:** Main Action · **Attribute:** Agility

**Target / range / shape:** One visible creature within your ranged weapon's range

Fire while moving between cover. The movement is part of this action and cannot exceed an open path.

- **Weak:** deal 2 weapon-type damage.
- **Standard:** deal 3 weapon-type damage and move 1 square.
- **Strong:** deal 5 weapon-type damage and move up to 2 squares.

**Duration:** Instant.

**Equipment / acquisition:** Requires a ranged weapon; personal scale only

---

**Tier / minimum level:** 1 · **DP:** 2 · **Requirements to learn:** Class Outlaw; minimum level 1

**Type:** Signature

**Tags:** Outlaw

**Limits:** Do not stack multiple instances of the same benefit; each granted Boon applies once. Pay the action and any stated time.

**ID:** signature-outlaw-running-shot
