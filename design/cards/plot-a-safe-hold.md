# Plot a Safe Hold

**Status:** Playtest proposal - untested.

## Rules

**Action:** Maneuver · **Attribute:** None (no roll)

**Target / range / shape:** One surveyed route with a known clear waypoint

Mark a holding point and the approach that avoids mapped obstructions. Moving hazards still require current observations.

**Duration:** Instant unless the effect states a duration.

**Equipment / acquisition:** Requires any equipment named above. Grants no equipment.

**Type:** Skill / Utility

**Tags:** Navigation / Maneuver
