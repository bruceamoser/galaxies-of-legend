# Rig the Haul

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Reason

**Target / range / shape:** One load you can reach and a route you can inspect

Set up a lift or haul using available anchors and tackle. On completing 3 progress, secure or move the load to the declared destination within the tackle’s rating.

- **Weak:** 1 progress.
- **Standard:** 2 progress.
- **Strong:** 3 progress.

**Duration:** Progress remains on the declared task until it resolves or circumstances invalidate it.

**Equipment / acquisition:** Requires appropriate access and any equipment named in the effect.

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Athletics 2

**Type:** Skill / Utility

**Tags:** Athletics / Main Action

**Limits:** Spend the listed action. Resolve the printed result once.

**ID:** rig-the-haul
