# Bridge the Service Gap

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Knowledge

**Target / range / shape:** One accessible damaged personal-scale connection or fixture

Build a service bypass within the equipment’s safe limits. On completing 3 progress, restore the named function for the scene. A bypass does not restore a ship system die.

- **Weak:** 1 progress.
- **Standard:** 2 progress.
- **Strong:** 3 progress.

**Duration:** Progress remains on the declared task until it resolves or circumstances invalidate it.

**Equipment / acquisition:** Requires appropriate access and any equipment named in the effect.

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Engineering 2

**Type:** Skill / Utility

**Tags:** Engineering / Main Action

**Limits:** Spend the listed action. Resolve the printed result once.
