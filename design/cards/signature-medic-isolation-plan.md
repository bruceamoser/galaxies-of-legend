# Isolation Plan

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Knowledge

**Target / range / shape:** One accessible treatment area; one hour

Separate clean and exposed work using supplies and barriers already available. This grants no immunity.

- **Weak:** Identify the main route of contamination.
- **Standard:** Establish marked clean and exposed zones and a safe transfer path if feasible.
- **Strong:** Also set up a second path for removing contaminated equipment.

**Duration:** Instant unless an outcome states a duration.

**Equipment / acquisition:** Requires the access, tools or equipment stated above.
