# Trace Access

*You follow the access trail before you touch the lock.*

**Status:** Playtest proposal - starter coverage, untested.

## Rules

**Action:** Main Action · **Attribute:** Knowledge

**Target / range / shape:** One accessible terminal or network; ten minutes

Investigate one access path or data record. The SA sets progress, usually 3. This finds a route; it does not automatically defeat security.

- **Weak:** 1 progress; leave a detectable access log.
- **Standard:** 2 progress; identify the next access barrier.
- **Strong:** 3 progress; gain a Boon on your next check against that identified barrier.

**Duration:** Information persists; Boon expires when that barrier changes.

**Equipment / acquisition:** Requires a terminal and physical or authorised network access

---

**Tier / minimum level:** 1 · **DP:** 2 · **Requirements to learn:** Computing 1

**Type:** Skill / Utility

**Tags:** Computing

**Limits:** One instance of this card's benefit per target or task; repeat only for new progress, a new trigger or a changed situation. Pay the printed action and time.
