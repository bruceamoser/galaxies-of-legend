# Program a Return

**Status:** Playtest proposal - untested.

## Rules

**Action:** Main Action · **Attribute:** Reason

**Target / range / shape:** One willing or crew-controlled robot within reach and one route you have walked; ten minutes

Record a return route the robot can traverse on its own. It stops at obstructions and takes no other actions during transit.

- **Weak:** Record the route. The robot needs a live command at each junction.
- **Standard:** Record the route. The robot can follow it on a single command.
- **Strong:** As Standard. It can also retrace the route to its starting position.

**Duration:** Until overwritten

**Equipment / acquisition:** Robot with working navigation and access to its controls

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Class Technician; minimum level 3

**Type:** Signature

**Tags:** Technician

**Limits:** Pay the action and stated time. This card grants no improvement to installed system dice.
