# Sensor Sweep

*You send a pulse into the dark and listen to what comes back changed.*

## Rules

**Action:** Main Action · **Attribute:** Reason

**Target / range / shape:** One vessel, structure or area within sensor range

Scan the target using [Perception and contacts](../rules/perception.md). The SA states what the instrument can measure and sets progress if the task needs a track (usually 3).

- **Weak:** 1 progress and a contact if there is a readable return.
- **Standard:** 2 progress and classify one return by its measurable signature.
- **Strong:** 3 progress and identify one feature if the return and reference data support it. Otherwise report the clearest classification and what would confirm it.

**Duration:** Record when the reading was taken. A moving contact can leave the last known location.

**Equipment / acquisition:** Requires a sensor pack or ship sensors

---

**Tier / minimum level:** 1 · **DP:** 2 · **Requirements to learn:** Science 1

**Type:** Skill / Technical

**Tags:** Technical / Utility

**Limits:** Repeatable. At a ship sensor station this replaces the ordinary acquire check and uses the station’s system check and effective range.

**ID:** sensor-sweep
