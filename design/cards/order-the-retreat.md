# Order the Retreat

**Status:** Playtest proposal - untested.

## Rules

**Action:** Reaction · **Attribute:** None (no roll)

**Target / range / shape:** One willing ally within comms whose planned route just became blocked

Identify one visible alternate route. They may abandon their movement before entering the blocked space.

**Duration:** Instant unless the effect states a duration.

**Equipment / acquisition:** Requires any equipment named above. Grants no equipment.

---

**Tier / minimum level:** 3 · **DP:** 4 · **Requirements to learn:** Command 2

**Type:** Skill / Utility

**Tags:** Command / Reaction

**Limits:** Pay the listed action each use. Any granted Boon applies once and does not stack with itself.
