# Reserve the Exit

**Status:** Playtest proposal - untested.

## Rules

**Action:** Passive · **Attribute:** None (no roll)

**Target / range / shape:** Self, while directing a crew in a scene

Once per scene before the crew separates, name one known rally point and a fallback. Each ally who hears you can repeat those instructions accurately.

**Duration:** Instant unless the effect states a duration.

**Equipment / acquisition:** Requires any equipment named above. Grants no equipment.

---

**Tier / minimum level:** 7 · **DP:** 8 · **Requirements to learn:** Command 3

**Type:** Skill / Utility

**Tags:** Command / Passive

**Limits:** Applies only under the circumstances stated above.

**ID:** reserve-the-exit
