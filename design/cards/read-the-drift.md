# Read the Drift

*You watch the way debris moves and choose the lane the chart does not show.*

## Rules

**Action:** Main Action · **Attribute:** Reason

**Target / range / shape:** One route, hazard field or orbital approach

Plot a safe passage. The SA sets the progress needed (usually 3).

- **Weak:** 1 progress; note one hazard the route must avoid.
- **Standard:** 2 progress; identify a safe lane.
- **Strong:** 3 progress; the lane grants a Boon to the next Piloting check made on this route.

**Duration:** The route knowledge persists for the journey.

**Equipment / acquisition:** None

---

**Tier / minimum level:** 1 · **DP:** 2 · **Requirements to learn:** Piloting 1

**Type:** Skill / Navigation

**Tags:** Navigation / Support

**Limits:** Repeatable; pay the action and any stated costs each use.
