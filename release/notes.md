# Release notes

## v0.1.0 — initial playtest data

First build of *Galaxies of Legend* on the Legend System chassis.

- Four homeworlds and twenty traits.
- Four cultures and four backgrounds, each a paired discipline and ability.
- Six classes: Soldier, Scientist, Spacer, Explorer, Medic, Envoy.
- Nine disciplines and forty-eight ability cards, including universal actions.
- Ten equipment entries and a market.
- Core rules, harm and recovery, starships and FTL.
- Player's Book PDF built with Typst.

This is a playtest edition. Ship Hull, DR, FTL clocks and the wound table are seed values. Interior art is a placeholder; the cover and crest are final assets.
