# Initial release review

Target: v0.1.0 digital playtest. The repository contains one Player’s Book, not a complete multi-book line.

The catalog has 4 homeworlds, 20 traits, 4 cultures, 4 backgrounds, 6 classes, 9 disciplines, 48 abilities and 10 equipment entries. Index and structural audit passed on 2026-11-01. These checks do not establish balance.

Corrected ship Hull wounds to trigger affected-system Consumable Die rolls rather than automatic degradation, and clarified shield DR before Hull. This restores Bruce’s agreed ship procedure; no character chassis change is introduced.

Release limitations: interior placeholders; four deferred classes; no adversary catalog or pregenerated characters; ship values, wound table and FTL targets require table testing. The exotic fuel has no fixed element name or price. Navigation task time and capacitor charging rate require SA adjudication. These limitations must accompany the PDF.

Before a public final edition: test complete character creation, combat, healing, power transfer and jump preparation; resolve fuel/time economy; develop threats and a starter scenario; check level 1/3/7 signatures and progression through level 10; approve art rights and final layout. Initial playtest publication does not imply any of these are complete.

Build evidence: 58-page PDF compiled with the available Typst Python runtime 0.15.0. The repository specifies CLI 0.15.1; that exact runtime was not available in this environment. A rendered overview was reviewed for page flow. Brand typography and colors applied from the supplied guide. Final print proofing remains outstanding.
